## 🚀 Что умеет KadrForge Studio

**KadrForge Studio** — это настольная студия полного цикла для создания видеороликов без рутины. Вы выбираете нишу или разбираете конкурентов, а программа сама собирает готовый к публикации ролик вместе с обложками и SEO-пакетом.

* **🔍 Анализ вирусных конкурентов:** исследует нишу, находит успешные форматы с высокими охватами, разбирает их хуки первых секунд, формулы удержания и переносит оптимальные параметры в настройки ролика одной кнопкой **«Применить анализ к настройкам»**.
* **🧠 Сценарии с удержанием (Retention-First):** строит динамичный сценарий с мощным хуком первых 2–3 секунд, открытыми петлями и строгим соблюдением выбранной тематики без смешивания рубрик.
* **🎙️ Профессиональная озвучка:** синтез речи через **Gemini TTS** с автоматическим резервным переключением на нейросетевой голос **Edge-TTS** (`ru-RU-DmitryNeural`).
* **🖼️ Гибридный подбор и генерация кадров:** поиск проверенных реальных кадров по теме с фильтрацией мусора и автоматическая AI-догенерация сцен через **Imagen 3 / Gemini Image**.
* **🎞️ Автоматический монтаж в FFmpeg:** плавный Ken Burns zoom/pan, склейка сцен, вшитые читаемые субтитры и поддержка форматов **9:16** (Shorts / Reels / TikTok) и **16:9** (YouTube).
* **🎨 Пакет вирусной упаковки (`seo_pack.txt`):** 4 кликабельных варианта заголовка, 3 готовые превью-обложки (`thumb_1.jpg` – `thumb_3.jpg`) с контрастными плашками, описание, хештеги и SEO-теги.
* **🔄 Встроенная система обновлений:** проверка новых версий прямо из окна программы и сборка чистых ZIP-релизов в один клик.

## 🛠️ Быстрая установка и запуск

1. Скачайте актуальный архив **`KadrForge_Studio_v1.3.1.zip`** из раздела [**Releases**](https://github.com/blek5000/kadrforge-updates/releases/latest).
2. Распакуйте архив в удобную папку без кириллических спецсимволов в пути (например, `C:\KadrForge`).
3. Запустите **`install.bat`** — скрипт создаст изолированное окружение `.venv`, установит зависимости и вынесет ярлык **«KadrForge»** на Рабочий стол.
4. Откройте программу с ярлыка на Рабочем столе, проверьте **Gemini API Key** и лицензию в блоке **4** и запускайте сборку.

---

## 🔄 Как обновиться без потери настроек

При выходе новой версии программа уведомит вас при запуске или по кнопке **«Проверить обновления»**:

1. Скачайте новый архив из окна обновления или со страницы [**Releases**](https://github.com/blek5000/kadrforge-updates/releases).
2. Распакуйте файлы поверх текущей папки программы с заменой, **не удаляя** свой `config.json`, папку `.venv` и каталог `output`.
3. Запустите **KadrForge Studio** — все ключи, лицензия и готовые ролики останутся на месте.

## 🚀 Что умеет KadrForge Studio

**KadrForge Studio** — это настольная студия полного цикла для создания видеороликов без рутины. Вы выбираете нишу или разбираете конкурентов, а программа сама собирает готовый к публикации ролик (или целую пачку до 20 роликов) вместе с обложками и SEO-пакетом.

* **🔍 Анализ вирусных конкурентов (`freellmpool`):** исследует нишу, находит успешные форматы с высокими охватами, разбирает их хуки первых секунд, формулы удержания и переносит оптимальные параметры в настройки ролика одной кнопкой **«Применить анализ к настройкам»**.
* **🧠 Сценарии с удержанием (Retention-First):** строит цельную историю про одного конкретного героя с мощным хуком первых 2–3 секунд, единым визуальным якорем и строгим соблюдением выбранной тематики без смешивания рубрик.
* **🎙️ Профессиональная озвучка (`RoyalTechno Bot API`):** синтез речи через **ElevenLabs** (поддержка украинского, русского и английского языков, а также выбор кастомного Voice ID).
* **🎥 AI-видео и AI-кадры нового поколения (`RoyalTechno Bot API`):** генерация живых видеосцен через **Veo 3.1** и **Grok Imagine 1.5**, либо детализированных кадров через **Nano Banana Pro** с плавным движением камеры.
* **📦 Пакетная генерация (Batch Mode):** сборка от **1 до 20 уникальных роликов** за один запуск — для каждого выпуска автоматически создаётся свой неповторяющийся сюжет, озвучка, сцены, превью и SEO.
* **🎞️ Автоматический монтаж в FFmpeg:** плавный Ken Burns zoom/pan, склейка сцен под тайминг, вшитые читаемые субтитры и поддержка форматов **9:16** (Shorts / Reels / TikTok) и **16:9** (YouTube).
* **🎨 Пакет вирусной упаковки (`seo_pack.txt`):** 4 кликабельных варианта заголовка, 3 готовые превью-обложки (`thumb_1.jpg` – `thumb_3.jpg`) с контрастными плашками, описание, хештеги и SEO-теги + автоочистка временных файлов.
* **🔄 Встроенная система обновлений:** проверка новых версий прямо из окна программы и сборка чистых ZIP-релизов в один клик.

| Компонент | Требования |

| **LLM (сценарии)** | Локальный или сетевой **freellmpool** (`http://127.0.0.1:8080/v1/chat/completions`) |

## 🔑 Подключение RoyalTechno Bot API (обязательно перед стартом)

1. Зарегистрируйтесь в Telegram-боте по ссылке: 👉 **[RoyalTechno AI Bot](https://t.me/royaltechno_ai_bot?start=ref_m2BH6O5P)**
2. Пополните баланс **минимум на $5** — этого достаточно для первых тестов и сборки роликов.
3. Получите персональный API-ключ формата `rt_live_...` в меню бота.
4. Подробную пошаговую инструкцию по настройке ключей и лицензии смотрите в файле **[`ВАЖНАЯ_ИНСТРУКЦИЯ.md`](./ВАЖНАЯ_ИНСТРУКЦИЯ.md)**.

## 🛠️ Быстрая установка и запуск

1. Скачайте актуальный архив **`KadrForge_Studio_v1.4.3.zip`** из раздела [**Releases**](https://github.com/blek5000/kadrforge-updates/releases/latest).
2. Распакуйте архив в удобную папку без кириллических спецсимволов в пути (например, `C:\KadrForge`).
3. Запустите **`install.bat`** — скрипт создаст изолированное окружение `.venv`, установит зависимости и вынесет ярлык **«KadrForge»** на Рабочий стол.
4. Откройте программу с ярлыка на Рабочем столе, в блоке **4** вставьте **RoyalTechno Bot API Key** (`rt_live_...`), проверьте **freellmpool** и лицензию `KF-...`, после чего нажимайте **«ЗАПУСТИТЬ СБОРКУ РОЛИКА»**.

## 🔄 Как обновиться без потери настроек

При выходе новой версии программа уведомит вас при запуске или по кнопке **«Проверить обновления»**:

1. Скачайте новый архив из окна обновления или со страницы [**Releases**](https://github.com/blek5000/kadrforge-updates/releases).
2. Распакуйте файлы поверх текущей папки программы с заменой, **не удаляя** свой `config.json`, папку `.venv` и каталог `output`.
3. Запустите **KadrForge Studio** — все ключи, лицензия и готовые ролики останутся на месте.

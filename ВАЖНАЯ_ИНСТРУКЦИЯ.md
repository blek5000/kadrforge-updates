# ⚠️ ВАЖНАЯ ИНСТРУКЦИЯ: Активация, API-ключ и лицензия KadrForge Studio

Перед первым запуском генерации роликов обязательно настройте **лицензионный ключ** и **Google Gemini API Key**.

---

## 1. Где и как создать Google Gemini API Key

Программа работает через официальный **Google Gemini API** (модели Gemini, Imagen и Gemini TTS). Сторонние ключи от других сервисов не подойдут — нужен именно ключ из Google AI Studio (`AIza...`).

1. Перейдите в **Google AI Studio**: https://aistudio.google.com/ и войдите в свой Google-аккаунт.
2. В левом меню выберите пункт **Get API key** (или **API keys**).
3. Нажмите **Create API key**, выберите существующий или создайте новый проект.
4. Скопируйте полученный ключ (начинается с символов `AIza...`).

> 💡 **Лайфхак с бесплатными лимитами:** если на одном Google-аккаунте закончился дневной или минутный бесплатный лимит генерации, создайте второй ключ на другом Google-аккаунте и вставьте его в программу — всё продолжит работать.

---

## 2. Куда вставлять ключи в программе

1. Запустите **KadrForge Studio** и прокрутите окно вниз до блока **«4. ЛИЦЕНЗИЯ, API, ОБНОВЛЕНИЯ И СБОРКА РЕЛИЗА»**.
2. В поле **«Имя / email лицензии»** впишите имя или email, на который оформлена лицензия.
3. В поле **«Ключ лицензии (KF-XXXX-...)»** вставьте ваш лицензионный ключ и нажмите **«Проверить и сохранить ключ»**.
   - Справа сверху в заголовке блока загорится зелёный статус **«ЛИЦЕНЗИЯ АКТИВНА»**.
4. В поле **«Gemini API Key»** вставьте ключ из Google AI Studio (`AIza...`).
5. При нажатии **«ЗАПУСТИТЬ СБОРКУ РОЛИКА»** или **«Проверить и сохранить ключ»** все данные автоматически сохранятся в файл `config.json`.

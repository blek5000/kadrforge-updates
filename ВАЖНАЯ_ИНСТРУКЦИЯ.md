⚠️ ВАЖНАЯ ИНСТРУКЦИЯ: Лицензия, RoyalTechno Bot API и настройка KadrForge Studio

Перед первым запуском генерации роликов обязательно настройте лицензионный ключ, RoyalTechno Bot API Key (для озвучки, AI-кадров/видео и превью) и подключение к freellmpool (для сценариев и анализа конкурентов).

1. Где и как получить RoyalTechno Bot API Key

Озвучка сцен (ElevenLabs), генерация AI-видео (Veo 3.1, Grok Imagine 1.5), AI-кадров и превью-обложек (Nano Banana Pro) работают через RoyalTechno AI Bot.

Перейдите в Telegram-бот по ссылке: 👉 RoyalTechno AI Bot

Запустите бота и пройдите быструю регистрацию.

Пополните баланс минимум на $5 — этого хватит для первых тестов и сборки роликов.

Откройте в боте раздел API / Ключи доступа и сгенерируйте свой персональный ключ (начинается с символов rt_live_...).

Скопируйте полученный ключ.

2. Куда вставлять ключи в программе

Запустите KadrForge Studio и прокрутите окно вниз до блока «4. ROYALTECHNO BOT API, FREELLMPOOL, ЛИЦЕНЗИЯ И РЕЛИЗ».

В поле «RoyalTechno Bot API Key (озвучка + видео + превью)» вставьте скопированный ключ (rt_live_...).

(Необязательно) В поле «ElevenLabs Voice ID» можно указать 20-символьный ID конкретного голоса; если оставить поле пустым — используется голос по умолчанию.

Нажмите кнопку «Проверить RoyalTechno API», чтобы убедиться, что ключ активен и баланс виден программе.

Проверьте строку freellmpool (по умолчанию: http://127.0.0.1:8080/v1/chat/completions, модель auto) — через него генерируются сценарии и разбор конкурентов.

В поле «Имя / email лицензии» впишите имя или email, на который оформлена лицензия.

В поле «Ключ лицензии (KF-XXXX-...)» вставьте ваш лицензионный ключ и нажмите «Проверить и сохранить настройки».

Справа сверху в заголовке блока загорится зелёный статус «ЛИЦЕНЗИЯ АКТИВНА», а все параметры автоматически сохранятся в файл config.json.
